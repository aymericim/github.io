📥 Importer un calendrier Jira (.ics)
Comment exporter depuis Jira :
1. Ouvre ton calendrier Jira → icône ⚙ ou menu "…"
2. Clique sur Export ou Télécharger (.ics)
3. Sélectionne le fichier téléchargé ci-dessous

Le filtre se base sur CATEGORIES:leaves et le nom du collaborateur est lu depuis SUMMARY.
👤 Collaborateurs non reconnus
Ces noms trouvés dans le calendrier Jira ne correspondent à aucun membre actuel de l'équipe. Cela peut être un collaborateur qui a quitté l'équipe : vous pouvez ignorer ses congés, ou les associer à un membre existant.

🔗 Configuration GitHub Gist
Étapes de configuration :
1. Va sur github.com/settings/tokens/new
2. Donne un nom (ex: scrumboard), sélectionne le scope gist uniquement
3. Génère et copie le token (commence par ghp_)
4. Crée un Gist sur gist.github.com (secret, fichier scrumboard.json, contenu {})
5. Copie l'ID du Gist depuis l'URL : gist.github.com/username/ID
